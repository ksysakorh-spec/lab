Что такое Git и для чего он используется?



Git - это программа которая сохраняет изменения в файлах. Нужна чтобы можно было вернуться к старой версии и чтобы несколько человек могли работать над одним проектом.



В чём разница между централизованными и распределёнными системами контроля версий?



В централизованных вся история на одном сервере без него не поработаешь. В распределённых у каждого своя копия можно работать без интернета.



Что такое репозиторий в Git?



Репозиторий - это папка с проектом за которой следит Git. Внутри есть скрытая папка .git там хранится история. Бывает локальный (на компе) и удалённый (на GitHub).
