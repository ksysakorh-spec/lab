git clone - скачать проект с GitHub к себе
git status - посмотреть что я поменяла
git add - выбрать файлы, которые сохраню
git commit - сохранить изменения
git push - отправить сохранённое на GitHub
git pull - забрать изменения с GitHub к себе
git init - сделать папку проектом чтобы Git за ней следил
git log - посмотреть список всех сохранений
git branch - посмотреть список веток
git checkout - переключиться на другую ветку
git merge - склеить две ветки в одну
git remote - посмотреть с каким GitHub связан проект
